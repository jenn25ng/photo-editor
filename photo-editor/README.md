# 🎨 꾸미사진

**인스타그램에 올리기 전, 사진을 예쁘게 꾸미는 웹 에디터**
피드(4:5)·스토리(9:16) 규격에 맞춰 손글씨·텍스트·이모지·기호로 꾸미고
고해상도 이미지로 저장하세요. 설치 없이 `index.html`만 열면 실행됩니다.

## ✨ 기능

- 🖼️ **배경** — 사진 업로드 + 배경색 선택
- 📐 **인스타 규격** — 피드 **4:5**(1080×1350), 스토리 **9:16**(1080×1920)
- ✍️ **손글씨(펜)** — 색·굵기 자유 드로잉 + 지우개
- 🔤 **텍스트** — 다양한 폰트(손글씨·귀여운·고딕·영문 멋진체) · 색상
- 😊 **이모지** — 애플(아이폰) 스타일 이모지 *(아래 참고)*
- ᴥ **기호 이모티콘** — `˚₊· ͟͟͞͞➳❥` `⋆｡°✩` 같은 SNS 감성 특수문자 모음
- ⭐ **스티커** — 장식용 이모지·기호
- ↔️ **드래그 편집** — 개체를 손가락으로 이동, 코너 핸들로 **크기·회전** (인스타 스토리처럼)
- ↩️ **되돌리기** / 🧹 **전체 지우기**
- 💾 **저장** — 인스타 규격 **1080px 고해상도 PNG** 다운로드
- 📱 마우스·터치·펜 모두 지원

## 🍎 애플(아이폰) 이모지 안내

이모지는 **기기의 기본 이모지 폰트**로 표시됩니다.
- **아이폰에서 열면 자동으로 애플 이모지**로 보여요. ✅ (따로 설정 불필요)
- 갤럭시 등 다른 기기에서는 그 기기의 이모지로 보입니다.
- 모든 기기에서 애플 이모지로 *강제* 하려면 애플 이모지 이미지셋이 필요하지만,
  이는 애플 저작권 대상이라 기본 버전에는 포함하지 않았습니다.

## 🚀 실행 방법

### 파일로 바로 열기
`index.html`을 브라우저로 열면 됩니다. *(폰트/이모지 웹폰트 로딩을 위해 인터넷 연결 권장)*

### 로컬 서버 (권장)
```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

### GitHub Pages 배포
저장소 **Settings → Pages → Branch = main / root** 설정 시
`https://jenn25ng.github.io/photo-editor/` 로 접속 가능합니다.

## 🗂️ 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조(툴바 + 캔버스 무대) |
| `style.css`  | 라이트 테마 스타일, 반응형 |
| `app.js`     | 편집 로직(개체 모델·드래그·저장) |

## 🛠️ 사용 기술

- 순수 **HTML / CSS / JavaScript** (프레임워크 없음)
- HTML5 **Canvas** (배경·손글씨·고해상도 합성 저장)
- **DOM 개체 + Pointer Events** 로 이동·크기·회전
- **Google Fonts** 웹폰트

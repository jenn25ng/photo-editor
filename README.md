# 🍼 아기랑 – 우리 아기 미디어 놀이터

**부모님이 골라주는 안전한 아기 미디어 앱.**
넘버블럭스(한국어·영어), 페파피그, 뽀로로, 코코멜론 등 유명한 어린이 프로그램을
**시즌 순서대로** 골라 볼 수 있어요. 설치 없이 `index.html`만 열면 실행됩니다.

## ✨ 특징

- 🧸 **캐릭터로 고르기** — 큰 카드에서 좋아하는 캐릭터를 탭
- 📺 **시즌별 순서 재생** — 각 시즌의 공식 재생목록을 앱 안에서 순서대로 자동 재생
- 🇰🇷🇺🇸 **한국어 / 영어 전환** — 두 언어가 모두 있는 프로그램은 버튼 하나로 전환
- 👶 **아기 친화 UI** — 큰 터치 영역, 아기자기한 파스텔, 모바일·태블릿 우선
- 🔒 **안전** — 부모가 고른 프로그램만 보여주고, 무작위 추천/외부 이동을 최소화
- ⚡ **의존성 없음** — 순수 HTML/CSS/JS + 유튜브 임베드

## 📚 수록 프로그램

| 프로그램 | 언어 | 재생 |
|---|---|---|
| 🔢 넘버블럭스 (Numberblocks) | 한국어·영어 | 시즌 1~2 앱 재생 / 이후 공식 채널 |
| 🔤 알파블럭스 (Alphablocks) | 영어 | 시즌 1 앱 재생 / 이후 공식 채널 |
| 🐷 페파피그 (Peppa Pig) | 한국어·영어 | 시즌 1 앱 재생 / 이후 공식 채널 |
| 🐧 뽀롱뽀롱 뽀로로 (Pororo) | 한국어·영어 | 공식 채널 |
| 🎵 코코멜론 (Cocomelon) | 영어 | 전체 에피소드 앱 재생 |
| 🦈 핑크퐁·아기상어 (Pinkfong) | 한국어·영어 | 공식 채널 |
| 🐶 블루이 (Bluey) | 영어 | 공식 채널 |
| 🐾 퍼피 구조대 (PAW Patrol) | 한국어·영어 | 공식 채널 |

> 시즌에 **공식 재생목록 ID가 등록된 경우** 앱 안에서 순서대로 재생되고,
> 아직 없는 시즌은 **해당 프로그램의 공식 유튜브 채널**로 안전하게 연결됩니다.

## ▶️ 실행 방법

```
index.html 을 브라우저에서 열기
```
또는 간단한 정적 서버로:
```
python3 -m http.server 8000   # → http://localhost:8000
```

## 📱 폰에 앱처럼 설치하기 (홈 화면 추가)

이 앱은 **PWA**라서 앱스토어 없이 홈 화면에 아이콘으로 추가할 수 있어요.

1. 앱을 인터넷에 올립니다 (예: GitHub Pages, Netlify 등 무료 정적 호스팅)
2. 폰 브라우저로 그 주소를 엽니다
3. **아이폰(사파리)**: 공유 버튼 → *홈 화면에 추가*
   **안드로이드(크롬)**: 메뉴(⋮) → *홈 화면에 추가 / 앱 설치*
4. 홈에 🍼 아이콘이 생기고, 누르면 전체 화면 앱처럼 실행됩니다.

> 앱 껍데기는 오프라인에서도 열리지만, 영상 재생은 유튜브라 인터넷이 필요해요.

## ✏️ 프로그램·시즌 추가/수정

모든 콘텐츠는 [`data.js`](./data.js) 한 파일에 있습니다. 유튜브 재생목록 주소의
`list=` 뒤 값(재생목록 ID)만 넣으면 앱에서 바로 순서대로 재생됩니다.

```js
{ n: 3, title: { ko: "시즌 3", en: "Series 3" },
  list: { en: "여기에_재생목록_ID", ko: "여기에_재생목록_ID" } },
```

- `list` 값이 없는 시즌은 자동으로 **공식 채널/검색 열기** 버튼이 됩니다.
- 새 프로그램은 `SHOWS` 배열에 항목 하나를 추가하면 됩니다.

## ⚠️ 저작권 안내

이 앱은 영상을 저장하거나 재배포하지 않습니다. 각 프로그램의 **공식 유튜브 채널이
무료로 공개한** 재생목록을 유튜브 임베드로 그대로 불러와 보여줄 뿐입니다.
재생목록은 채널 사정에 따라 바뀔 수 있어, `data.js`에서 손쉽게 갱신할 수 있게 했습니다.

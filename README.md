# 🎨 꾸미사진

**인스타그램에 올리기 전, 사진을 예쁘게 꾸미는 웹 에디터**
피드(4:5)·스토리(9:16) 규격에 맞춰 텍스트·특수 글씨체·감성 기호로 꾸미고
고해상도 이미지로 저장하세요. 설치 없이 `index.html`만 열면 실행됩니다.

## ✨ 기능

- 🖼️ **배경** — 사진 업로드 + 배경색 선택 · **확대(슬라이더/두 손가락 핀치)·드래그로 위치 이동(크롭 효과)**
- 📐 **인스타 규격** — 피드 **4:5**(1080×1350), 스토리 **9:16**(1080×1920)
- 🔤 **텍스트** — 인스타 감성 무료 폰트 19종(손글씨·귀여운·고딕·명조·영문) · 색상 · **여러 줄 입력**
- 🔠 **글씨 변환** — 영문·숫자를 `𝐁𝐨𝐥𝐝`·`𝑩𝒐𝒍𝒅`·`Ⓐⓑ`·`Ａｂ` 등 **완전히 다른 글씨체**로 (유니코드라 어느 기기서나 동일)
- ✨ **스토리 스타일 프리셋** — 원터치 **클래식·모던·네온·타자기·스트롱** (무료 폰트+CSS 효과로 재현)
- ᴥ **감성 템플릿** — `˚₊· ͟͟͞͞➳❥` `⋆｡°✩` 같은 **폰으로 못 치는 SNS 감성 특수문자**(하트·별·꽃·얼굴·구분선·괄호 등)
- 😊 **이모지** — **Twemoji** 기반, **아이폰·갤럭시 어느 기기서나 똑같은 모양**으로 보이는 이모지(이미지로 삽입 → 저장해도 동일)
- ⭐ **스티커** — 장식용 특수기호(★ ☆ ♥ ✦ …)
- ↔️ **드래그 편집** — 개체를 손가락으로 이동, 코너 핸들로 **크기·회전** (인스타 스토리처럼)
- ↩️ **되돌리기** / 🧹 **전체 지우기**
- 💾 **저장** — 인스타 규격 **1080px 고해상도 PNG** 다운로드
- 📤 **인스타 공유** — 편집물을 공유시트로 전달 → **인스타 스토리/게시물**로 올리기 *(아이폰 권장, 아래 참고)*
- 📱 마우스·터치 모두 지원

## 🌐 왜 이 앱인가요? (아이폰 없어도 인스타 감성)

아이폰은 인스타 스토리 기본 폰트로 감성 있게 꾸미기 쉽지만,
**갤럭시 등 다른 기기에선 그 폰트·감성이 안 나옵니다.** 이 앱은 그 격차를 메웁니다:

- **웹폰트**로 감성 글씨체를 직접 불러와서 **아이폰·갤럭시 상관없이 똑같이** 보여요.
- **글씨 변환**과 **감성 특수문자(템플릿)** 는 유니코드라, 기기 기본 키보드로는 못 만드는 글씨·기호를 그대로 쓸 수 있어요.
- 결과물은 **이미지(PNG)로 저장**되므로, 어디에 올려도 폰트·기호가 깨지지 않습니다.
- 이모지는 **Twemoji(이미지)** 로 넣어서, 기기 기본 이모지에 의존하지 않고 **아이폰·갤럭시 어디서나 똑같은 모양**으로 보이고 저장돼요.

## 📤 인스타로 올리기

- **아이폰(사파리)**: `📤 인스타 공유` → 공유시트에서 **Instagram** 선택 → **스토리/게시물**로 올리기 (Web Share API 사용)
- 지원하지 않는 브라우저에서는 자동으로 **사진 저장**으로 대체돼요. 저장된 사진을 인스타 앱에서 올리면 됩니다.
- ⚠️ 웹앱이 인스타에 **자동 게시**하는 건 불가능해요. 인스타 게시 API는 비즈니스 계정·서버·심사가 필요하며 개인 계정엔 열려있지 않습니다. 그래서 "공유하기" 방식을 사용합니다.

## 🚀 실행 방법

### 파일로 바로 열기
`index.html`을 브라우저로 열면 됩니다. *(감성 웹폰트 로딩을 위해 인터넷 연결 권장)*

### 로컬 서버 (권장)
```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

### GitHub Pages 배포
저장소 **Settings → Pages → Branch = main / root** 설정 시
`https://jenn25ng.github.io/photo-editor/` 로 접속 가능합니다.

## 🛠️ 사용 기술

- 순수 **HTML / CSS / JavaScript** (프레임워크 없음)
- HTML5 **Canvas** (배경·고해상도 합성 저장)
- **DOM 개체 + Pointer Events** 로 이동·크기·회전
- **Google Fonts** 웹폰트
